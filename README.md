# CosmoSafe 🧴

An intelligent cosmetic safety analysis and recommendation system.

## Features
- Search cosmetic products by name or brand
- Scan product labels using OCR
- Get risk score and harmful chemicals list
- Receive safer product recommendations

## Tech Stack
Python 3.12, Flask, Pandas, EasyOCR, RapidFuzz, Scikit-learn

## Dataset
- California CDPH Chemicals in Cosmetics dataset
- Indian e-commerce cosmetics dataset (not accurate) gonna remove this later

## SDG Alignment
SDG 3 — Good Health and Well-Being

## Setup
```bash
pip install -r requirements.txt
python preprocess.py
python app.py
```
